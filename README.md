# ppt-study

用 Vite、React 和 TypeScript 搭建的期末复习页。左侧预览课程 PPT，右侧阅读 AI 逐页讲解，两栏按原始页码平滑同步。桌面端可拖动中间分隔线，手机上采用上下布局。

## 本地运行

使用 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。运行 `npm run build` 生成 `dist/`，运行 `npm run preview` 可在本机预览构建结果。

## 使用方式

1. 首次打开时可直接开始使用。点击左上角的名称可切换到已有工作区，也可以选择「新建」并输入名称。
2. 在左侧上传 `.pptx` 或 `.pdf` 课件。上传后，点击文件名旁的「更换」可以重新选择。PDF 按文件页序逐页预览，旧版 `.ppt` 可在 PowerPoint 中另存为 `.pptx`。
3. 在右侧点击「复制提示词」，把提示词和课件发给你的 AI。将生成的 Markdown 粘贴到右侧，格式校验通过后会进入阅读模式。需要修改时，点击「编辑讲解」。
4. 滚动任意一栏，另一栏会跟到对应页。也可通过两栏上方的翻页按钮或页码框定位。

工作区、课件和讲解保存在当前浏览器中。刷新后会打开上次使用的工作区。清除站点数据会删除已保存的工作区。PowerPoint 的复杂效果可能和浏览器预览有差异。
